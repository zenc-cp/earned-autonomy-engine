Two-Plane Earned Autonomy Graduation Engine

Pre-action governance authorizes what an agent may attempt. An isolated, read-only verification plane independently checks delivered bytes and protected ledger invariants after execution, graduating or auto-demoting each action class from signed, build-pinned evidence.

API / runtime path (proposed live) One-way evidence / readback (no commands back) Focal graduation & revocation path (local prototype)

Per-Action Isolation

Read and write action classes earn autonomy independently. Passing 3 verified read_loan runs never graduates extend_due_day.

Fail-Closed Revocation

One bound contradiction on protected row L42 sets a sticky Tier 0 / HOLD across all classes until a new build fingerprint and signed reinstatement exist.

Prototype Boundary

Documents the two-plane reference architecture, not a deployed production system. Local Ed25519 keys stand in for an enterprise HSM/PKI verifier identity.
